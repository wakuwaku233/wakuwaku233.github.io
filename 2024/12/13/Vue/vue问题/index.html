Vue 单页应用与多页应用的区别

概念：

  • SPA单页面应用（SinglePage Web Application），指只有一个主页面的应用，一开始只需要加载一次js、css等相关资源。所有内容都包含在主页面，对每一个功能模块组件化。单页应用跳转，就是切换相关组件，仅仅刷新局部资源。
  • MPA多页面应用 （MultiPage Application），指有多个独立页面的应用，每个页面必须重复加载js、css等相关资源。多页应用跳转，需要整页资源刷新。

为什么ref和reactive要同时存在？

特性 ref reactive
目标类型 基本类型 + 对象（自动转 reactive） 对象/数组
返回值 { value: T } Proxy 代理对象
模板使用 自动解包 .value 直接访问属性
类型推断 简单直接 需显式标注复杂类型
组合式函数适用性 天然支持解构 需 toRefs 转换

设计哲学：
ref 和 reactive 的并存是为了覆盖不同场景的需求，提供更灵活的选择。ref 是“响应式的基本单元”，而 reactive 是“响应式容器”，二者互补而非替代。

vue3的静态提升

什么是静态提升

在 Vue 3 里，模板编译时会分析模板中的节点，把那些不会改变的静态节点提取出来，并且只创建一次，而非在每次渲染时都重新创建，这就是静态提升。这能减少虚拟 DOM 的创建与比较开销，从而提升渲染性能。

静态提升的工作原理

Vue 3 的编译器会对模板进行分析，找出其中的静态节点。这些静态节点不会在组件的生命周期内发生变化，例如纯文本、静态 HTML 标签等。编译器会将这些静态节点提升到渲染函数外部，使其仅在初始化时创建一次，后续渲染时直接复用。

静态提升的优势

  • 减少虚拟 DOM 创建开销：静态节点仅需创建一次，后续渲染时无需重新创建，减少了虚拟 DOM 的创建成本。
  • 减少虚拟 DOM 比较开销：由于静态节点不会改变，所以在虚拟 DOM 比较时可以直接跳过，减少了比较的工作量。

总结

Vue 3 的静态提升是一种有效的编译优化策略，通过将静态节点提取到渲染函数外部，减少了虚拟 DOM 的创建与比较开销，提升了应用的渲染性能。在开发 Vue 3 应用时，合理利用静态提升可以让应用更加高效。
